# Week-3
This report presents a complete statistical analysis and hypothesis testing study in Python, based on a business problem: whether a redesigned checkout page improves the shopping experience of an online store compared with the old design. I generated a reproducible dataset of 2,400 sessions using NumPy, split equally between the two designs, and recorded checkout time, conversion, device type, customer segment and order value. Four hypotheses were formulated and tested at a 5% significance level. A Welch t-test showed that the new design reduces checkout time significantly. A chi-square test showed that it also increases the conversion rate, from about 11.6% to 16.5%. A chi-square test of independence showed that conversion depends on device type, with desktop users converting most. A one-way ANOVA with Tukey post-hoc comparisons on log-transformed order values showed that new customers spend significantly less than returning and loyal customers. Before each test I checked assumptions using Shapiro–Wilk, Levene's test and Q-Q plots, and I validated results with non-parametric alternatives. I also reported effect sizes, 95% confidence intervals, a power analysis and a Bonferroni correction for multiple testing. The report includes the Python code, seven visualisations, an interpretation of each result, business recommendations and a discussion of limitations. The full code and dataset are included.
